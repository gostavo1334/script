EXCEL DATA RANGE TO TELEGRAM BOT
==================================

This script captures ONLY your Excel data (not the whole screen or window)

WHAT IT DOES:
- Opens your Excel file in the background (no window popping up)
- Goes to the sheet you specify
- Captures ONLY the data range (with images/charts) as a clean PNG
- Sends the image to your Telegram group
- Also sends the Excel file (optional)

COMMANDS (for PowerShell):
--------------------------

1. Send active Excel file immediately:
   .\run_excel_to_telegram.bat --now

2. Send a specific Excel file:
   .\run_excel_to_telegram.bat --file "C:\path\to\your_file.xlsx" --now

3. Send a specific sheet from a file:
   .\run_excel_to_telegram.bat --file "your_file.xlsx" --sheet "Sheet1" --now

4. Send a specific range (e.g., A1:G50):
   .\run_excel_to_telegram.bat --file "your_file.xlsx" --range "A1:G50" --now

5. Schedule daily at 15:30 (3:30 PM):
   .\run_excel_to_telegram.bat --time "15:30" --file "your_file.xlsx" --sheet "Data"

6. Send only the image (not the Excel file):
   .\run_excel_to_telegram.bat --file "your_file.xlsx" --now --no-file

7. Use a custom caption:
   .\run_excel_to_telegram.bat --file "your_file.xlsx" --now --caption "Daily Sales"

8. Set a permanent caption:
   .\run_excel_to_telegram.bat --set-caption "My Default Caption"

TROUBLESHOOTING:
----------------
- "No file specified" - You must provide --file "your_file.xlsx"
- "Sheet not found" - Check the exact sheet name in Excel
- "Range not valid" - Use format like "A1:G50" or "B2:M100"
- "Excel not found" - Make sure Microsoft Excel is installed

BEST PRACTICE:
--------------

2. Create Basic Task

7. Check "Run with highest privileges"
